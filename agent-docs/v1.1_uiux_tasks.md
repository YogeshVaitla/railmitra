# 🎨 UI/UX Agent Task Specification: Seat Swap V1.1 Polish

> **Role**: React Native Styling, Reanimated Animations, Micro-interactions
> **Context**: We delivered V1, but the initial manual testing revealed some stiff animations and confusing visual hierarchies.
> **Key Objective**: Smooth out the Home Screen hamburger menu animation, and design a top-level context header for the Swap Screen.

---

## 🍔 Ticket: RM-SW-070 — Fix Hamburger Menu Animation
**Priority**: P1 | **File**: `app/index.tsx`

### Context
When the user clicks the menu icon in the top left, the dark overlay (`menuBackdrop`) immediately snaps to 40% opacity (no fade-in at all). The drawer slide-in runs on a generic `Animated.spring` that feels too stiff.

### Tasks
1. Instead of a hardcoded `backgroundColor: 'rgba(0,0,0,0.4)'` appearing instantly, wrap the backdrop in an `Animated.View`.
2. Create an `Animated.Value(0)` named `backdropFade`.
3. Inside `openMenu()`, run `Animated.timing(backdropFade, { toValue: 1, duration: 250, useNativeDriver: true })` in parallel with the drawer slide. Interpolate that 0→1 to `rgba(0,0,0,0) → rgba(0,0,0,0.5)`.
4. In `closeMenu()`, fade it back to 0.
5. Soften the drawer's `menuSlide` spring. Currently `tension: 65, friction: 11`. Try `tension: 40, friction: 8` for a smoother rollout.

## 🔎 Ticket: RM-SW-071 — Train Context UI on Swap Screen
**Priority**: P1 | **File**: `app/swap.tsx`, `components/swap/swap.styles.ts`

### Context
The Frontend Agent (Ticket RM-SW-060) is moving the `trainNo` input to the top of `app/swap.tsx` so users can browse without registering. Your job is to make this look premium.

### Tasks
1. Design a sticky or collapsable header at the top of the Swap Screen.
2. If `trainNo` is empty, it should look like a prominent search/input prompt:
   - "Enter Train Number to See Swaps"
   - A clean `<TextInput>` with a magnifying glass or "Go" button.
3. If `trainNo` is set (e.g., `12423`), it should collapse into a sleek, read-only pill or mini-header displaying: `🚄 Train 12423 • Today`.
4. Add an "Edit" or "Change" small icon next to it so they can search a different train if they made a mistake.
5. Provide the JSX and styling updates to the Frontend Agent so they can wire the state logic into it.
